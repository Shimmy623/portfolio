FinTech & APIs

M-Pesa Daraja API Payment Engine

API Architecture

End-to-end Safaricom Daraja API integration architecture enabling Lipa Na M-Pesa Online (STK Push) checkouts, OAuth 2.0 credential lifecycle management, and asynchronous webhook reconciliation.

Problem: Web merchants lose conversions and face manual reconciliation errors without automated mobile-money prompts and verified callback logging.
Architecture: Server-side OAuth2 token caching, Base64 timestamp password generation, STK Push initiation, and idempotent callback receipt verification.
  • ✓Strict MSISDN normalization (`2547XXXXXXXX`) & payload validation.
  • ✓Idempotent `CheckoutRequestID` tracking to prevent duplicate credits.
  • ✓Graceful handling of ResultCodes (`0` Success, `1032` Cancelled, `1` Funds).
